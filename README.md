# CoRZs Game Launcher

Современный и легкий игровой лаунчер на базе **WPF (.NET 10)**, разработанный для быстрой проверки обновлений, управления файлами игры и запуска клиента.

---

## Структура проекта

- **`GameLauncher/`** — Графический интерфейс лаунчера (WPF).
- **`Launcher.Core/`** — Ядро лаунчера (логика проверки обновлений, статусы, управление файлами).
- **`run_launcher.bat`** — Скрипт автоматического запуска (проверяет .NET, при необходимости авто-устанавливает .NET 10 SDK, восстанавливает пакеты, собирает и запускает проект).
- **`publish_for_testers.bat`** — Скрипт сборки автономной версии для тестеров (`Self-Contained`).
- **`game.bat`** — Файл-заглушка для проверки работы кнопки «Играть».

---

## Быстрый старт (Для разработчиков и тестеров)

Просто дважды кликните по файлу **`run_launcher.bat`**:
1. Скрипт проверит наличие `.NET SDK` (если его нет — автоматически скачает и установит .NET 10 SDK).
2. Восстановит необходимые NuGet-зависимости.
3. Соберет проект и запустит лаунчер.

---

## Сборка версии для тестеров

Если вам нужно отправить лаунчер людям для тестирования без необходимости устанавливать `.NET` на их компьютеры:
1. Запустите **`publish_for_testers.bat`**.
2. Готовая автономная папка со всеми файлами появится по пути:
   `GameLauncher/bin/Release/net10.0-windows/win-x64/publish/`
3. Поместите туда файл **`game.bat`** (заглушку игры).
4. Запакуйте эту папку в `.zip` архив и отправьте тестерам.
